# حُکم — مینی‌اپ تلگرام

یک بازی کامل و فارسیِ حکم برای مرورگر و Telegram Mini App؛ با یک بازیکن انسانی و سه حریف/هم‌تیمی هوش مصنوعی. پروژه‌ی فرانت‌اندِ استاتیک است و برای اجرا به سرور، دیتابیس یا کلید API احتیاج ندارد.

## اجرا در محیط توسعه

```bash
npm install
npm run dev
```

برای بررسی نسخه‌ی قابل انتشار:

```bash
npm test
npm run build
npm run preview
```

خروجیِ آماده‌ی انتشار در پوشه‌ی `dist/` قرار می‌گیرد.

## انتشار serverless

پروژه را می‌توان روی Vercel، Netlify یا Cloudflare Pages به‌عنوان سایت استاتیک منتشر کرد. برای Vercel تنظیمات `vercel.json` از قبل اضافه شده است:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

هیچ تابع سروری در این نسخه لازم نیست. برای افزودن بازی چندنفره‌ی هم‌زمان، رتبه‌بندیِ قابل‌اعتماد یا ذخیره‌ی حساب کاربری باید بعداً یک سرویس همگام‌سازی/تابع serverless اضافه شود.

## اتصال به Telegram

1. پروژه را روی یک نشانی HTTPS منتشر کنید.
2. در گفت‌وگو با `@BotFather` یک Mini App بسازید یا نشانی را به‌عنوان Web App / Menu Button ربات ثبت کنید.
3. نشانیِ منتشرشده را به‌عنوان URL مینی‌اپ قرار دهید.

SDK رسمی Telegram Web App در `index.html` بارگذاری می‌شود؛ برنامه هنگام اجرا `ready()` و `expand()` را صدا می‌زند، رنگ پوسته را تنظیم می‌کند و در صورت وجود، نام کوچک کاربر را نمایش می‌دهد. داده‌ی `initDataUnsafe` فقط برای شخصی‌سازی رابط استفاده شده و **اعتبارسنجی هویت نیست**؛ قبل از هر قابلیت حساس یا چندنفره، `initData` را در سمت سرور اعتبارسنجی کنید.

## قوانین و امکانات

- چهار بازیکن، دو تیمِ روبه‌رو؛ ۱۳ کارت برای هر نفر.
- پنج کارت نخست به حاکم می‌رسد تا خالِ حکم را انتخاب کند.
- پیروی از خالِ زمینه اجباری است؛ حکم و رتبه‌ی کارت در تعیین برنده‌ی هر دور اعمال می‌شود.
- اولین تیمی که ۷ دور ببرد، دست را می‌برد؛ بردِ بدون واگذاری دور با دو امتیازِ مسابقه محاسبه می‌شود.
- سه بازیکن هوش مصنوعی، انیمیشن نوبت و کارت، راهنمای قوانین، آمار دست، صدای اختیاری و ذخیره‌ی وضعیت در `localStorage`.
- رابط راست‌به‌چپ، واکنش‌گرا و سازگار با فضای امن گوشی است. کارت‌ها با SVG/CSS ساخته می‌شوند و به تصویر خارجی وابسته نیستند.

## نکته‌ی فنی

منطق توزیع، پیروی از خال، برنده‌ی دور، انتخاب حکم و امتیازدهی در `src/game/engine.ts` قرار دارد و تست‌های آن با `npm test` اجرا می‌شوند. بازی فعلی تک‌نفره و محلی است؛ «دعوت» فقط پیوند را برای اشتراک‌گذاری می‌فرستد و بازیکن دیگر به همان میز زنده متصل نمی‌شود.
