# 🎴 ربات حکم تلگرام — PHP 8.2 / cPanel

ربات چهار نفره حکم برای هاست اشتراکی cPanel. با webhook اجرا می‌شود و به Python، SSH، پردازش دائمی یا cron نیاز ندارد. تیم‌ها صندلی‌های ۱ و ۳ و صندلی‌های ۲ و ۴ هستند. حاکم پنج کارت می‌بیند، حکم را انتخاب می‌کند و بازی با رعایت خال و ۱۳ تریک در هر دست ادامه می‌یابد.

## پیش‌نیازها

- PHP 8.2 با افزونه‌های **curl** و **mbstring**، فعال در cPanel MultiPHP Manager / Select PHP Version.
- دامنه HTTPS معتبر با گواهی عمومی، اتصال خروجی HTTPS به `api.telegram.org`، و مجوز نوشتن PHP در پوشه خصوصی.
- ربات BotFather و توکن آن؛ برای حالت اینلاین `/setinline` را فعال کنید.
- همه بازیکنان باید قبل از بازی در پیام خصوصی ربات `/start` بزنند، وگرنه تلگرام اجازه ارسال کارت‌ها را نمی‌دهد.

## نصب در cPanel

1. در File Manager پوشه `hokm-private` را در خانه حساب (کنار `public_html`، **نه داخل آن**) بسازید. فایل `config.example.php` را در آن با نام `config.php` کپی کنید. این فایل را هرگز در فضای عمومی یا Git قرار ندهید.
2. در `public_html` فایل‌های `webhook.php` و `bot.php` را آپلود کنید. این مسیرها فرض می‌کنند `public_html` مستقیماً زیر پوشه خانه حساب است. اگر از document root متفاوت استفاده می‌کنید، مسیر `$configFile` در `webhook.php` را با مسیر مطلق فایل خصوصی خود جایگزین کنید.
3. در `hokm-private/config.php` توکن، شناسه‌های عددی ادمین و مسیر مطلق `state_file` را تنظیم کنید؛ مثلاً `/home/USERNAME/hokm-private/state.json`. مقدار `webhook_secret` را به یک رشته تصادفی ۳۲ تا ۲۵۶ کاراکتری متشکل از حروف انگلیسی، ارقام، `_` و `-` تغییر دهید. پوشه خصوصی باید برای PHP قابل نوشتن باشد؛ فایل وضعیت و فایل قفل به طور خودکار ساخته می‌شوند. دسترسی عمومی به این پوشه را ممنوع نگه دارید؛ فایل وضعیت شامل دست‌های خصوصی بازیکنان است.
4. PHP 8.2 و افزونه‌های بالا را برای دامنه فعال کنید. در صورت نصب زیرپوشه، آدرس عمومی را مطابق آن تغییر دهید.
5. webhook را **یک بار** با درخواست زیر ثبت کنید (از رایانه خود یا ترمینال cPanel؛ مقادیر را جایگزین کنید):

   ```bash
   curl -X POST "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" \
     --data-urlencode "url=https://example.com/webhook.php" \
     --data-urlencode "secret_token=<WEBHOOK_SECRET>" \
     --data-urlencode 'allowed_updates=["message","callback_query","inline_query"]'
   ```

   پاسخ باید `"ok":true` باشد. توکن را در تاریخچه مشترک، لاگ یا اسکرین‌شات منتشر نکنید. اجرای polling قبلی را متوقف کنید؛ هر ربات فقط یک webhook دارد.
6. در گروه `/table عنوان` بزنید، چهار نفر بنشینند و شروع کنند. در حالت اینلاین `@BotName عنوان` را انتخاب کنید و دکمه ساخت میز را بزنید.

## دستورات

`/start`, `/help`, `/rules`, `/id`, `/table [عنوان]`؛ ادمین‌ها: `/admin`, `/close ID`, `/cleanup`, `/broadcast متن`. پاک‌سازی خودکار هنگام ساخت میز انجام می‌شود؛ `/cleanup` همه میزهای شروع‌نشده و میزهای تمام‌شده منقضی را می‌بندد. برادکست فقط به چت‌های شناخته‌شده میزهای معمولی ارسال می‌شود؛ تلگرام شناسه چت پیام‌های اینلاین را در اختیار ربات نمی‌گذارد.

## پشتیبان و امنیت

از `hokm-private/state.json` با رعایت محرمانگی نسخه پشتیبان بگیرید. وضعیت قدیمی Python/Pickle با این نسخه سازگار نیست؛ بازی‌ها را از نو شروع کنید. همزمان چند نصب را به یک فایل وضعیت متصل نکنید مگر اینکه از همان قفل فایل روی یک سیستم فایل مشترک پشتیبانی شود. درخواست‌های webhook سریالی و با قفل پردازش می‌شوند. اگر ذخیره‌سازی پس از ارسال پیام به تلگرام شکست بخورد، تلگرام ممکن است به‌روزرسانی را دوباره ارسال کند؛ از فضای دیسک و دسترسی نوشتن مطمئن شوید.

## عیب‌یابی

- در `getWebhookInfo` وضعیت و `last_error_message` تلگرام را بررسی کنید: `https://api.telegram.org/bot<BOT_TOKEN>/getWebhookInfo` (این URL محرمانه است).
- خطای 403: مقدار secret ثبت‌شده در تلگرام و فایل تنظیمات یکسان باشد. پس از تغییر secret دوباره `setWebhook` را اجرا کنید.
- خطای 500: مسیر تنظیمات و وضعیت، مجوز پوشه، نسخه PHP و افزونه‌ها را بررسی کنید؛ خطاهای PHP را در cPanel ببینید.
- دست خصوصی نمی‌رسد: هر بازیکن باید `/start` زده باشد و ربات را بلاک نکرده باشد.
- میز اینلاین در چت مقصد قابل ویرایش است، اما امکان ارسال اطلاعیه جداگانه یا برادکست به آن چت وجود ندارد.

## تست محلی

با PHP 8.2 و افزونه‌های لازم: `php -l bot.php && php -l webhook.php && php tests/game.php`. برای تست کامل، webhook و یک ربات واقعی تلگرام لازم است.
